现有方法、结果与证据边界（请先读此文，再评价设计）

一、研究目标与当前状态
用户研究联邦类增量学习，关注完整十任务AIA、最终性能以及通信成本，希望分类器与共享子空间/历史约束/低秩更新形成实质联系，而不只是继承LoRM的RegMean或改个名字。目标是可支撑高水平投稿的问题与机制，不要求每个组件全部原创，也不接受为增加模块而堆模块。
当前工作基线：普通AdamW + selected route + Shared-A/B-only + rank64 RRS统计压缩 + 余弦Head-RegMean。用户已决定后续默认用压缩版，未决定新分类器。无近端，不恢复旧Muon/双侧近端，不重新引入三seed gate作为完整T10的前提。

二、实际实现的流程
1. ViT-B/16，ImageNet-21K预训练，12层Q/V适配器。每层DeltaW_Q=B_Q A，DeltaW_V=B_V A；适配器rank32。A在任务开始选定，任务内所有客户端共享并固定，正式只训练B和当前任务头。不同任务A可以不同。
2. 用当前任务训练输入的patch token统计S=sum x x^T（未去均值；不含CLS token），累计历史统计H。H是各任务当时编码器下采集统计的和，不是用当前编码器重算的旧数据统计。RRS通过S v=lambda(H+epsilon I)v得到参考子空间，再做欧氏正交化。
3. 从T2起，训练集support/query划分；参考基附近64维候选空间内调整32维A，用两轮真实短程客户端AdamW更新、B加权聚合和头融合评价候选。query仅来自当前任务训练数据。候选接受要求all-seen query CE下降、当前任务内部CE不变差，并满足历史trace暴露、正交和信任范围约束。不使用旧类别样本直接验证旧类损失；trace代理不能保证旧准确率不降。
4. 正式每任务10客户端x5轮x5epoch，batch16；B AdamW lr0.0002余弦，head AdamW lr0.001，weight decay均为0。AdamW状态按客户端/轮重新建立。B按本地样本数FedAvg；共享A使sum p_k B_k A=(sum p_k B_k)A。该等式只在参数更新层成立，不自动意味着深层CLS特征响应低秩或局部分类头在全局特征上仍最优。
5. 每个客户端训练完后，用自身局部终态编码器采集归一化CLS特征Gram，服务器对当前任务余弦头做Head-RegMean。其有效权重行归一化，目标是sum tr[(U-U_k)G_k(U-U_k)^T]，带每行单位范数约束；G_k非对角收缩系数0.5。Gram原始和已含样本计数，不再重复乘N_k。旧任务头冻结；训练CE仅当前任务类别；推理在全部已见类别中argmax。
6. 任务结束将BA一次合并到主干，将当前RRS统计一次加入历史。RRS统计的当前压缩：客户端本地做谱分解，F=FP32(U64 sqrt(Lambda64))，d=FP32(max(diag(S)-diag(FF^T),0))；传F、d及44字节头/诊断；服务器仅用S_hat=FF^T+diag(d)选基、构候选池、约束历史暴露、累计H。无全Gram旁路。该近似PSD、近似保持对角/trace，但不是原S的Loewner上界。
7. 当前短程响应的头反向含既有隐式代理。tracked/direct前向一致、算子或小状态机测试通过，不等于整个选基链是精确真实超梯度。新头要重新检查其前向、梯度和状态恢复。

三、指标与主对比
AIA_T=100/T * sum_{t=1..T} a_t，其中a_t为学完第t任务时在当时全部已见类上的原始argmax准确率；不是最终任务行的平均。CIFAR100每类测试数相同，最终总体准确率等于最终各任务准确率均值，但仍不同于AIA。
主指标原始raw；辅助fixed-centered：每任务10类logit块减去自身均值，再在全部已见类argmax，不使用真实任务ID。两种读出均报告；不依据分数切换主指标。
设置为100类/10任务、10客户端、Dirichlet alpha0.05，相同seed0 manifest/类别顺序与预训练来源。U0/C0分别fresh T1-T10，不复用旧T1。每条轨迹500客户端轮、125万正式训练图次、79350更新，十次阶段重载及最终已合并checkpoint额外10000图重载均通过。

重要：以下仅是设计草案，均未实现/训练。来自前面对话，不代表用户已经选定最终方案。

候选A：统一全局统计头 + 实际聚合更新驱动的类别统计传输
动机：局部头与全局编码器失配；旧类别统计随主干更新过时。RRS决定参数方向、共享A与B聚合提供明确DeltaW，但分类语义没有自动跟随。
流程设想：客户端在聚合后的同一全局编码器上收集当前类n/mu/压缩散布；根据DeltaW_l=DeltaB_l A_l的方向JVP或更新前后配对CLS特征估计响应子空间P，学习接近恒等T=I+P K；把旧mu/Sigma近似传到当前坐标，建立覆盖已见类的统一统计判别器（LDA/岭回归/其他候选由Pro论证）。
必须解决：旧类只可由当前数据外推，可能失败；低秩参数不保证最终特征低秩；已有RRS patch Gram是无标签且不含CLS，不能直接拿来恢复类语义/分类协方差；不同坐标统计不能直接相加；类协方差聚合需均值差修正；标签/先验/校准参数不能用测试集调。局部训练临时头与最终推理头的关系、selected短响应如何使用同一真实分类器必须说清。
候选与主线的潜在联系应通过实际DeltaB A及测得的全局CLS响应体现，而非只给普通漂移补偿改名。现有LDC/SDC/LR-RGDA等已有重叠，不能直接宣称新颖。

候选B：只在实际响应子空间中校正分类器，避免完整头Gram
设P为最终特征空间d x q正交基，W0为逐行归一化后的有效参考头，z_g为聚合后全局特征，候选W=W0+D P^T。以本地真实输出相对W0 z_g的残差r_k为目标，h=P^T z_g；平方目标min_D sum||D h-r_k||^2+lambda||D||^2只需上传S_k=sum h h^T（q x q）和R_k=sum r_k h^T（当前类别数 x q），不需要d x d Gram。线性无范数约束时D=(sum R_k)(sum S_k+lambda I)^(-1)。
若保留余弦头，不能直接岭回归再归一化就宣称原目标最优。可固定W_perp=W0(I-PP^T)，W=W_perp+E P^T，逐行约束||E_c||^2=1-||W_perp,c||^2，解低维球面二次问题；边界半径为零、FP32部署和不可行/病态条件需处理。
q64、10类、FP32时S/R核心数组18944字节，而当前头Gram4718592字节。这个约99.6%仅是核心数组尺寸差，不含P构造/广播、W0/全局B下发、共同编码器上的额外前向、选基超梯度通信与缓存。
P必须在分布式约束下由实际CLS响应得到，不能上传全Gram或原始特征再称通信低，也不能直接用中间层A。若选择任务级固定P，要检验后续轮的覆盖；若轮间更新，要计入所有消息。保留稳定正交补，不将全部分类特征强制降到q维。
若仅校正当前任务头，它也不会自动解决旧头随主干变化的时间漂移，必须单独说明。它仍属广义响应匹配/受限RegMean家族，并非天然“除了RegMean之外”的全新目标。只有实际响应子空间比同维普通投影/通用映射有额外价值，才有机制证据。

候选C：直接对头Gram套低秩+对角codec
可作为必要的通信控制，验证问题究竟是编码开销还是融合机制；并不因易实现或压缩有效，就自动作为最终创新。头Gram特征分布与RRS patch Gram不同，RRS codec成功不能直接保证头融合效果、数值稳定或梯度一致性。

希望Pro的判断：若A/B都不值得做，请提出更自然的替代，明确问题、机制为何必要、数学目标、客户端/服务器过程、历史信息、与现有主线的交互、全部消息与关键证伪实验。不要把AIA79.61与86.18的差直接解释成可由任何一个新头恢复的收益。
