# 真实 Muon 旧响应代理与服务器一致性实验

## 结论

单种子 T3 探索的预注册联合条件**未通过**：完整方法相对既有匹配 control 的净纠正为 0/3000，低于预设的至少 6/3000；完整方法五轮均未接受候选，也未达到至少接受一轮的条件。其余冻结指标通过不改变失败结论。三条新臂的每轮候选均回退到当轮 FedAvg，不代表更广泛的响应保护方法不可行。代码与协议预先固定于提交 `4455b9fd5a792e6fe3d364ef5d1b97f7a43c411d`。

| 方法 | T3 全类准确率 | 旧类准确率 | 新类准确率 | 遗忘 | 接受轮数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 既有 control：真实 Muon + 标准聚合 | 91.0% | 94.1% | 84.8% | 1.4% | 不适用 |
| full：旧响应代理 + 客户端一致性 | 91.0% | 94.1% | 84.8% | 1.4% | 0/5 |
| no_consensus：关闭客户端一致性系数 | 91.0% | 94.1% | 84.8% | 1.4% | 0/5 |
| kl_only：仅 KL 响应 | 91.0% | 94.1% | 84.8% | 1.4% | 0/5 |

三新臂相对 control 的正确变错、错变对、错换错均为 0；相应测试集逐图预测一致。独立 CPU 读取三个端点后，核对其 24 个 B 矩阵均与 control 逐元素相同；这项比较不包括分类头。旧类、遗忘和候选两个消融的汇总比较只说明本次单种子短序列结果。

## 机制与观察

只使用当前任务输入，旧 T2 teacher 提供旧类 KL 和旧类 logsumexp 偏移组成的响应代理；在实际 FedAvg 锚点聚合各客户端梯度及其 Muon 五步 SSB，构造固定、带信赖半径的候选。候选必须在 fit 中降低代理且不增加 all-seen 和 current CE，才会部署；候选固定后确认集仅用于观察。两种消融分别移除方向一致性系数或偏移项，完整数学和阈值见预注册协议。

15/15 轮均构造了候选，旧响应代理均下降，但 15/15 轮 current CE 超过容忍值；full 和 no_consensus 的 10/10 轮 all-seen CE 也上升，kl_only 的 all-seen CE 仅 2/5 轮上升。因冻结联合选择条件，每轮均精确回退。以 full 第一轮为例，fit 旧响应差 −0.001152485、all-seen CE 差 +0.000580934、current CE 差 +0.000407209。这个结果提示给定代理方向在这些锚点存在当前样本损失权衡，不能证明旧类行为受到保护或判断其他方向的可行性。完整方法五轮客户端方向一致性余弦约 0.7083–0.7125；它们是此特定代理和梯度的统计，不是完整本地轨迹偏差。
