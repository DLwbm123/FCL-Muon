============================================================
3. 方法的数学定义
============================================================

先说明单层；全模型为各适配矩阵块的和。

W = W0 + B A
A: [r, d_in]
B: [d_out, r]
A A^T = I_r
D: B 的实际增量
DeltaW = D A

因此 ||DeltaW||op = ||D||op，||DeltaW||F = ||D||F。

默认 LoRA scale s=1，初始化时 assert。若今后支持 s!=1，必须一致修改：
DeltaW=s D A，
H=s^2 A C A^T / Z，
F=s R A^T / Z，
并转换 B 空间与权重空间谱半径。第一版不默默支持非单位 scale。

历史风险：
q_k(B) = q0_k + <F_k,B> + 0.5 tr(B H_k B^T)，H_k PSD。
k 表示客户端；它汇总该客户端的全部历史阶段，不是每个历史任务的单独最坏风险。

默认对有历史数据的客户端均匀加权 pi_k=1/K_history；当前任务 FedAvg 仍按训练样本数加权。
这两种权重的作用不同，不能混用。
全模型历史目标为各适配层归一化风险的平均，层权重 a_l=1/L，L=24。
可配置 client risk weighting，但默认及改变必须写进 metadata。

对每层：
H_l = a_l sum_k pi_k H_kl
F_l = a_l sum_k pi_k F_kl
q0_l = a_l sum_k pi_k q0_kl

服务器广播同一组 H_l,F_l,q0_l 给所有客户端，任务内固定。

M = 当前任务方向估计，使用既定 baseline 即将送入 polar/NS 的矩阵。
M 不包含历史风险修正。若使用 FedMuon，M 包含其原有控制变量校正。

在每个本地 minibatch，对每个 B 解：
D* = argmin_{||D||op <= eta} phi(D)
phi(D) = <M,D> + lambda_history [q(B+D)-q(B)]

令：
G = M + lambda_history (F + B H)
Hhat = lambda_history H

则：
phi(D) = <G,D> + 0.5 tr(D Hhat D^T)

执行：
B <- B + D

eta 是实际 B 增量的谱半径，已经包含该研究分支的学习率和确定性 shape scaling。
不要在返回 D 后再次乘 lr。
不要在返回 D 后再做 polar、NS、奇异值均衡、RMS 归一化、额外 shape scaling 或未纳入目标的 decay。
分类头沿用原训练流程，相关保证只针对上述适配矩阵代理。

这是软历史代价 + 硬谱步幅。不要报告“每个旧任务风险都不增长”或“严格无遗忘”。

============================================================
4. 精确累计历史统计与归一化
============================================================

采用数值较稳定的、以本任务全局 W0 为中心的充分统计。
每客户端、每层存原始累计量：

C_k = sum_history x x^T                     [d_in,d_in]
R_k = sum_history (W0 x - y_anchor) x^T      [d_out,d_in]
e_k = 0.5 sum_history ||W0 x-y_anchor||^2    scalar
z_k = sum_history ||y_anchor||^2            scalar
n_k = historical token count               scalar

x 是登记历史时的层输入；y_anchor 是对应阶段最终全局模型的该矩阵输出 W_anchor x。
不保留 x、y 或 W_anchor，只保留这些统计。
若模块有 bias，这里的 y_anchor 只取线性部分 W_anchor x，不直接使用含 bias 的模块输出；否则会破坏新锚点残差为零的定义。
对 fused QKV 模块，准确提取 Q/V 权重切片以及它们共同的原始输入，不能误用 attention 混合后的输出。

保存额外 metadata：
- task_id、center/base model version/hash；
- layer/projection 标识；
- 统计 transform 与 token 选择；
- 数值 dtype、累计 token 数；
- normalization rule；
- schema_version。

默认 Z_k = max(z_k, energy_floor * n_k * d_out)，energy_floor 可配置，首版数值默认 1e-12。
若 n_k=0，返回空历史零 core，不除以零。
统计归一化只在构造 core 时进行，原始累计量不提前除均值。
Z 的值及是否触发 floor 要记录；这只是防止数值除零，不是额外历史正则。

任务开始时，用当前共同 A 投影：
H_k = A C_k A^T / Z_k
F_k = R_k A^T / Z_k
q0_k = e_k / Z_k

于是：
q_k(B) = [e_k + <R_k A^T,B> + 0.5 tr(B A C_k A^T B^T)] / Z_k

同一客户端 Q/V 的实际输入完全相同时，允许共享 C；R,e,z 按投影分别存。
不要仅因维度一样就共享不同输入的统计。

精度：
- CPU 累计统计建议 FP64 参考模式，或者 FP32 累计配合明确误差测试；
- 训练 core 与 solver 至少 FP32，不在 BF16/FP16 下求解 QR/SVD 和 gap；
- 使用 AMP 时，先 unscale 当前梯度，再构造方向 M；overflow/skip step 的处理沿用原训练器，不能更新一个事实上未执行的 solver cache；
- B 或其实际用于更新的 master parameter 使用 FP32；若保存/计算 dtype 产生额外舍入，最终审计实际执行的 B_after-B_before，不能把提议 D 的证书冒称为另一个实际更新的证书；
- 测试使用 FP64；
- H 显式对称化，检查 PSD；
- 只允许按数值容差修正微小负特征值；明显非 PSD 要报错定位，不能直接大幅裁剪掩盖状态错误；
- e 与 q 理论非负，记录因舍入出现的小负数；不要用大范围 clamp 让错误消失。

任务内 C,R,e,z 和 center W0 不变。
B 是从该任务 W0 出发的累计位移。
FedAvg 轮之间更新 B，不重新移动历史中心。

============================================================
5. 任务边界的更新顺序：必须严格实现
============================================================

当前任务最后一轮聚合得到全局 B_end，A 仍是本任务共同基。

步骤 1：用旧历史状态重心更新。
DeltaW = B_end A

使用旧 C、旧 R、旧 e 计算：
e_new = e_old + <R_old,DeltaW>
        + 0.5 tr(DeltaW C_old DeltaW^T)
R_new = R_old + DeltaW C_old

等价可用旧 H_raw=A C_old A^T、F_raw=R_old A^T：
e_new = e_old + <F_raw,B_end>
        + 0.5 tr(B_end H_raw B_end^T)

先计算 e_new，再覆盖 R，或显式使用 old 状态。
不要误用已经归一化的 H/F 更新原始 e。

步骤 2：合并。
W0_new = W0_old + B_end A
更新历史 state 的 center_id，使它与这个最终全局模型一致。
在统计前向之前，立即禁用/移除当前 adapter 或把已合并的 B 清零，确保有效权重只包含一次 B_end A；不要在 W0_new 上再次叠加未清除的 adapter。
验证合并前最终全局模型与合并后统计模型的前向输出在容差内相同。

步骤 3：用最终全局合并模型登记当前任务数据。
每个客户端对自己仍可访问的当前训练数据做一次 deterministic、eval-mode、no_grad 前向。
默认 patch tokens only、排除 CLS；沿用明确的统计预处理，并记录。
只使用当前训练 split，不能用 test 或旧训练样本。
对每个被适配矩阵收集：
C_current = sum x x^T
z_current = sum ||W0_new x||^2
n_current = number of tokens

新数据以 W0_new 为锚点，所以它给 R_new、e_new 的新增项为零。
因此：
C <- C_old + C_current
R <- R_new
e <- e_new
z <- z_old + z_current
n <- n_old + n_current

必须先完成旧历史重心更新，再把 C_current 加入。
如果先加 C_current 再计算旧历史变化，会错误地给新登记数据制造风险。

步骤 4：下一任务。
按原 MuLoRA RRS 重选 A_new，B=0，投影新的历史 core。
按 baseline 规则重置任务相关动量/FedMuon控制状态。
清除 solver warm-start cache。
保留累计 C,R,e,z,n，不能跟随 optimizer reset 一起清空。

如果某客户端本任务没有数据，它仍需按全局 DeltaW 移动其旧历史中心，只是不登记新数据。
正式主协议100%参与，但不要把这种基本状态一致性写错。

============================================================
6. 小矩阵谱 QP 求解器
============================================================

接口建议：
solve_spectral_qp(G, Hhat, eta, previous_delta=None, config=...)
  -> actual_delta, diagnostics

不要把整个训练器、动量和历史统计塞进求解器。

输入：
G [d_out,r]，Hhat [r,r] PSD，eta>=0。
目标：
phi(D)=<G,D>+0.5 tr(D Hhat D^T)，||D||op<=eta。

特殊情况：
- eta=0：返回零，并正确计算诊断；
- G=0：选择零最优解；
- Hhat=0：返回 -eta * compact_polar(G)；
- compact_polar 在零奇异值上取零，G=0不能返回任意正交矩阵；
- 任何使用 rank tolerance 的近似都须记录，并用原始 G 复核 gap；
- Hhat 可以奇异，不要默认逆矩阵存在。

一般情形：
1. reduced QR: G=Q T，Q^T Q=I。
2. 存在最优解 D=Q X。
3. 解 r×r 问题：
   min <T,X> + 0.5 tr(X Hhat X^T)
   s.t. ||X||op<=eta。
4. 还原 D=Q X，并在原始 d_out×r 空间复核目标、谱半径与 gap。

谱球投影：
Z=U diag(s) V^T
Proj(Z)=U diag(min(s,eta)) V^T
逐个裁剪奇异值，不是统一 Frobenius normalization。

推荐参考算法：
- projected gradient，或带目标单调检查/restart 的加速 projected gradient；
- 梯度 T+X Hhat；
- Lipschitz 常数 L=lambda_max(Hhat)，L=0使用线性问题特殊分支；
- 保存 best feasible iterate；
- 加速导致目标上升时重启，不以最后一步无条件覆盖最优可行点；
- optional: Hhat 正定且条件允许时先求无约束解 -G Hhat^{-1}，用 solve 而不是显式 inv；若可行直接采用；
- 不默认添加 ridge/damping。若支持，作为改变目标的显式配置，默认0。

停止与证书：
原始空间 K=G+D Hhat，
FW gap = <K,D> + eta * ||K||_*。

对可行 D，gap 是此凸问题的最优性差距上界。
小空间的对应公式可以用于内循环，但最终用原始空间复核。
记录：
- objective phi；
- gap、relative_gap；
- actual operator norm 与 feasibility residual；
- iterations；
- converged；
- zero_step；
- warm_start_used；
- warm_start_objective；
- elapsed time；
- numeric precision。

建议实现可配置默认值，而不是把它们当论文官方值：
max_iter=200；
FP32 reference pilot: gap_rtol=1e-4，gap_atol=1e-10；
FP64 tests: 根据问题尺度使用更严格阈值。
relative scale 可用 eta*||G||_*，并明确数值下限。
真实训练前检查容差与该分支实际量级是否相容。

达到 max_iter：
返回 best feasible，标注 converged=false；
不要声称精确解；
不要悄悄无限加迭代；
记录未收敛比例，必要时在有限诊断上改容差/算法。
同时记录零步比例，不能靠总返回0伪装成功。

代理非增：
D=0 可行、phi(0)=0。
返回的 best feasible 应满足 phi<=数值容差；否则回退0并记录 numerical_failure。
这是代理证书，不是旧风险单独不增或真实 CE 不增。

============================================================
7. 借鉴 OSD 后增加：有检查的热启动
============================================================

OSD 使用跨步 warm start；我们借用原则，不复制其硬约束对偶变量。

每步 QR 的 Q 会变化，禁止直接复用旧 X。
每客户端、每层保存上一个“实际 D_prev”，以及 task/basis identity。

本步：
X_warm = Q_new^T D_prev
X_warm <- 谱球投影(X_warm, eta_current)

计算本步新目标 phi_warm：
- 若可行且 phi_warm <= 0，从 warm start 开始；
- 否则从0开始；
- 不能因为上一目标下降，就默认在当前目标仍下降；
- 可比较零点和其他可行候选，选本步目标最小者。

FedAvg 广播或学习率变化后仍需重新验证；任务/basis更换时清空 cache。
solver cache、momentum、FedMuon controls、历史统计是不同生命周期的状态。

支持 warm_start=off/on 开关。
验证两种初始化都解同一个问题；不能用精度更差的warm start假冒加速。
报告实际 wall time、平均迭代数与最终 gap。

============================================================
8. 动量、半径、lambda：不要混淆尺度
============================================================

保留现有 faithful MuLoRA-FL / FedMuon 的实现和配置。
新增研究分支有独立 method name。

尤其注意：
beta*m + g 与 beta*m + (1-beta)*g，
bias correction，
Nesterov，
FedMuon correction，
在纯 polar 中可能有等价的整体尺度关系，在历史 QP 中会改变 lambda 的意义。

direction_provider 必须输出：
- baseline 原本将送入 polar/NS 的 M；
- 当前实际 eta（包含外部确定性缩放）；
- momentum/scaling convention 的 metadata。

历史项仅在 G=M+lambda(F+BH) 处加入一次。
禁止先把历史 risk 放入训练 loss/momentum，再在 QP 中重复加一次。

FedMuon 组合模式：
- 只在当前梯度/动量上使用原定义的 control correction；
- raw momentum 和 local/global controls 维持其原语义；
- 历史风险修正不能写回这些 controls；
- 按既定 task boundary 重置；
- 不自动继承原 FedMuon 的收敛定理，当前算法发生了变化。

已有审计提醒：
Takezawa supplementary 的实际 fedmuon_optimizer.py 与 standalone muon.py 并不相同。
若官方实现存在参数嵌套循环导致同一参数重复更新等明显实现错误，沿用项目此前按公式修正并记录的分支；不要为了“忠实”重新引入错误。
也不要强行让 MuLoRA 的 faithful 分支使用 Takezawa 的 NS 系数与缩放。

lambda_history 为固定、可配置实验超参数。
第一版不做在线自适应lambda，按各自方向估计约定调参。
至少记录：
r_grad = lambda*||F+B H||F/(||M||F+eps)
D_mu = -eta*compact_polar(M)
r_curv = [lambda/2 * tr(D_mu H D_mu^T)] /
         [-<M,D_mu>+eps]
history linear term = lambda*<F+B H,D_mu>
总量与逐层量都可统计。

不要不看风险归一化就只搜0.1/1/10。
提供 training-only 校准工具：
- 在第一个拥有有效历史统计的任务起点（通常任务2）校准；任务1无历史、曲率分母为零是预期情况。校准后在本次run后续任务固定lambda，不逐任务重校准；
- 不同lambda分支可复用同一任务1结束checkpoint，不能用任务2或未来数据反过来影响任务1训练；
- 从固定当前训练批次的 M,H 和 eta 得到尺度建议；
- 例如非退化批次上 lambda_ref = median(
  sum_l[-<M_l,D_mu_l>] /
  sum_l[0.5 tr(D_mu_l H_l D_mu_l^T)]
  )，剔除零分母并完整记录；
- H_l 已含层权重和客户端权重，不能重复计入；
- 这仅给尺度参考，随后可在 lambda_ref×{0.1,1,10} 上用固定验证协议选择；
- 校准保存恢复模型、optimizer、RNG和DataLoader/sampler状态，或明确计入训练预算；
- 不能读取旧训练数据或测试标签；
- 不在任务/通信轮中悄悄重校准；
- 校准值、来源批次及是否成功均写入配置快照。
若数据/验证条件不足，先完成工具和机制诊断，不输出“最优lambda”。

9. 方法注册与实验对照
============================================================

至少提供清楚分离的名称/配置，实际文件名可按仓库风格调整：

1. mulora_fl
完整忠实基线，不改它的 NS、momentum 或历史 RRS。
2. mulora_fedmuon_fl
现有 MuLoRA 参数化 + Takezawa FedMuon 的 FCL 适配，准确命名。
3. mulora_fl_exact_polar
机制参考：同数据、A、M、eta，使用 exact compact polar。
4. history_grad_muon
同样历史统计：
G=M+lambda(F+BH)，D=-eta*compact_polar(G)。
这里是同一当前M上的历史一阶修正；不把history反复累计进momentum。
5. history_spectral
主方法：完整有限步历史二次谱 QP。
6. history_frobenius_qp
同样历史统计和G/Hhat，但解：
min <G,D>+0.5 tr(D Hhat D^T)，||D||F<=rho。

第6项：
D=-G(Hhat+mu I)^{-1}，mu>=0，
可用特征分解及单调一维搜索mu。
Hhat奇异时正确处理边界和线性nullspace，不无条件使用inv。
当无约束解存在且可行时mu=0。
训练时rho有单独可调配置与公平验证预算。

主方法可切换 direction_provider=mulora/fedmuon；
先确保mulora provider的机制对照闭环，再运行fedmuon组合。
不要把provider变化和history目标变化混成同一个消融。

忠实复现与机制参考要分开：
lambda=0/no_history 的严格退化对象是 exact-polar Muon（第3项），
不保证逐位恢复 finite-NS 原基线。
每个结果表同时列 oracle/precision/momentum/shape_scale，避免用求解精度差异冒充方法收益。

可选：OSD-style baseline 接口说明即可，第一版不实现。
若后续添加，全权重约束应变为 U^T D(A V)=0，
不能写成 U^T D V=0 或 D V=0；
必须单独定义保护统计来源，并报告 constraint residual；
只能称适配基线，不能称原 OSD 复现。

10. 借鉴 OSD 后增加：同状态的更新几何诊断
============================================================

实现 paired_update_audit，固定同一个 checkpoint、同一个 minibatch、同一个 B/M/H/F。
不更新训练状态、不推进RNG或保存恢复相关状态。
比较上述各更新，记录：
- 当前预测收益 -<M,D>；
- 精确代理历史变化 q(B+D)-q(B)；
- 完整代理phi；
- ||D||F、||D||op；
- top singular value、stable rank、effective rank；
- ||D A||F/op 与 B-space 是否相等；
- 与普通Muon的方向夹角；
- 是否主要等价于普通Muon统一缩放。

提供 matched-energy 方向诊断：
G=M+lambda(F+BH)
D_frob_matched = -||D_spectral||F * G/||G||F
G=0时显式处理。
它只是匹配能量的方向对照，不是完整 Frobenius QP 最优解。

可额外使用 rho=||D_spectral||F 求完整 Frobenius QP；
这只匹配允许预算，不能保证最终实际范数一定相等。

严格禁止把主方法D事后放大到baseline norm以“公平比较”。
那会改变原问题、可能破坏谱半径和代理证书。
所有额外缩放的对照必须单独命名。

有效秩定义明确固定：
p_i=sigma_i/sum sigma；
effective_rank=exp(-sum p_i log p_i)；
stable_rank=sum sigma_i^2/max sigma_i^2。
零矩阵按明确约定返回0。
不要混用奇异值能量概率和奇异值幅度概率。
不声称更高有效秩必然更好。

client:

12. 真正需要的验收测试
============================================================

实现针对数学语义和状态风险的测试，不写只镜像实现细节的测试。

A. 充分统计一致性
随机小矩阵，至少3历史阶段、不同全局锚点、非等权样本；
显式sum ||W x-y||^2与 C/R/e 表示一致；
q梯度与有限差分一致；
归一化、客户端聚合和层权重只计入一次。

B. 任务边界递推
至少跨两个任务：
recenter前后同一实际W的历史q一致；
新登记数据初始风险0；
之后更换A重新投影，仍与显式历史响应一致；
每round不能重复recenter；
先加新C的错误应被此测试发现。

C. 解析二维例子
M=diag(2,1)，F=0，B=0，H=diag(100,1)，lambda=eta=1。
期望D=diag(-0.02,-1)，phi=-0.52。
普通Muon D=-I 的phi=47.5。
统一缩放Muon的最优alpha=3/101，phi=-9/202。
这是优化单元测试，不是FCL精度结果。

D. solver语义
PSD且奇异H、零G、零eta、很小eta、各向异性H；
||D||op可行；
phi不高于零（在数值容差内）；
FW gap达要求或诚实converged=false；
QR降维与原始目标一致；
精确compactpolar的rank-def/zero输入不注入任意nullspace更新。

E. warm start
Q坐标变化、eta变化、FedAvg改变B后的情况；
旧实际D运输正确；
坏warm start回退0；
与从0求出的高精度目标一致；
新任务清cache但保留history。

F. Muon退化
lambda=0和空history在exact研究分支匹配exact-polar基线；
eta/shape scaling只作用一次；
s=1下||DA||与||D||一致。
不要把finite-NS精确逐位匹配写成这条断言。

G. 共同历史目标与聚合
同A下实际权重平均恒等式；
公共凸q满足Jensen；
所有客户端的core hash相同。

H. checkpoint与无旧样本访问
中断恢复与不中断过程在可重复容差内一致；
history只登记一次；
新任务训练/统计collector不能读取旧train index；
评测访问与训练访问分离。
不要为了通过测试把所有数据一起放进训练loader。

13. 实验执行顺序与资源范围
============================================================

阶段0：只做数学与生命周期测试，CPU即可。
阶段1：真实数据smoke：
2 clients、2 tasks、2 rounds、每个本地阶段少量真实batch；
验证训练、聚合、任务末登记、resume、日志和统计。
smoke使用自己的清楚配置，不能覆盖正式设定。
使用合适的小rank/dim的单元测试不算真实benchmark。

阶段2：限定pilot：
CIFAR-100，前3个完整任务，10 clients，seed0，
alpha=0.5和0.05，
正式的round/epoch/batch/模型/头部设定。
优先运行已存在基线结果或直接复用完全相同manifest与代码版本的已完成结果，不重复花费计算。

"""Exact centered sufficient statistics; Q/V share only their identical input C."""
import torch
from .spectral_qp import checked_psd


class InputHistory:
    schema_version=1
    def __init__(self,din,dout,center='initial',energy_floor=1e-12):
        self.C=torch.zeros(din,din,dtype=torch.float64)
        self.risks={p:{'R':torch.zeros(dout,din,dtype=torch.float64),'e':0.,'z':0.} for p in ['q','v']}
        self.n=0;self.center=center;self.energy_floor=energy_floor;self.registered=set();self.moved=set()
        self.metadata={'schema_version':1,'token_policy':'patch_only_no_CLS','transform':'upstream deterministic test-form on current train',
                       'dtype':'torch.float64','normalization':'max(anchor_energy, energy_floor*n*dout)'}
    def recenter(self,task,deltas,new_center):
        if task in self.moved:raise ValueError('Repeated historical recenter')
        for p,d in deltas.items():
            d=d.detach().cpu().double();risk=self.risks[p]
            value=risk['e']+float((risk['R']*d).sum())+.5*float(((d@self.C)*d).sum())
            tolerance=1e-10*max(risk['z'],abs(risk['e']),1e-30)
            if value < -tolerance:raise ValueError('Negative raw historical residual energy')
            risk['e']=value  # Preserve tiny rounding negatives, do not hide them.
            risk['R']=risk['R']+d@self.C
        self.center=new_center;self.moved.add(task)
    def register(self,task,c,energies,n,center):
        if task not in self.moved or center!=self.center:raise ValueError('Must recenter old history before registration')
        if task in self.registered:raise ValueError('Repeated historical registration')
        if n<0:raise ValueError('Negative token count')
        self.C+=c.detach().cpu().double();self.n+=n
        for p in self.risks:self.risks[p]['z']+=float(energies[p])
        self.registered.add(task)
    def project(self,a,p):
        risk=self.risks[p];a=a.detach().cpu().double()
        if self.n==0:return {'H':a@self.C@a.T,'F':risk['R']@a.T,'q0':0.,'Z':0.,'floor_active':False,'n':0}
        floor=self.energy_floor*self.n*risk['R'].shape[0];z=max(risk['z'],floor)
        h,_,correction=checked_psd(a@self.C@a.T/z)
        return {'H':h,'F':risk['R']@a.T/z,'q0':risk['e']/z,'Z':z,'floor_active':risk['z']<floor,'n':self.n,'psd_correction':correction}


def risk_value(core,b):
    return core['q0']+(core['F']*b).sum()+.5*((b@core['H'])*b).sum()


def common_core(banks,bases,client_weights=None):
    """Uniform nonempty historical clients; a_l=1/(2*number of blocks)."""
    output=[];metadata=[];layer_weight=1/(2*len(bases))
    for name,a in bases.items():
        active=[k for k in banks if banks[k][name].n>0]
        weights={k:1/len(active) for k in active} if client_weights is None else client_weights
        for p in ['q','v']:
            projected=[(k,banks[k][name].project(a,p)) for k in active]
            zeroH=torch.zeros(a.shape[0],a.shape[0],dtype=torch.float64)
            dout=banks[next(iter(banks))][name].risks[p]['R'].shape[0]
            zeroF=torch.zeros(dout,a.shape[0],dtype=torch.float64)
            core={'H':zeroH,'F':zeroF,'q0':0.}
            for k,c in projected:
                factor=layer_weight*weights[k];core['H']+=factor*c['H'];core['F']+=factor*c['F'];core['q0']+=factor*c['q0']
                metadata.append({'block':name,'projection':p,'client':k,'Z':c['Z'],'floor_active':c['floor_active'],'n':c['n'],'client_weight':weights[k],'layer_weight':layer_weight})
            output.append(core)
    return output,metadata

"""Spectral-ball convex QP. Every certificate is evaluated on the returned step."""
import time
from dataclasses import dataclass
import torch


@dataclass
class SolverConfig:
    max_iter:int=200
    gap_rtol:float=1e-4
    gap_atol:float=1e-10
    warm_start:bool=True


def checked_psd(h):
    h=(h+h.T)/2
    values,vectors=torch.linalg.eigh(h)
    scale=max(float(values.abs().max()),1e-30)
    tol=64*torch.finfo(h.dtype).eps*h.shape[0]*scale
    if float(values.min()) < -tol:raise ValueError('Historical Hessian is materially non-PSD')
    correction=max(0.,-float(values.min()))
    if correction:h=(vectors*values.clamp_min(0))@vectors.T
    return h,values.clamp_min(0),correction


def compact_polar(g):
    u,s,v=torch.linalg.svd(g,full_matrices=False)
    tol=max(g.shape)*torch.finfo(g.dtype).eps*(float(s.max()) if s.numel() else 0)
    keep=s>tol
    return u[:,keep]@v[keep],tol


def spectral_project(x,radius):
    u,s,v=torch.linalg.svd(x,full_matrices=False)
    return (u*s.clamp_max(radius))@v


def objective(g,h,d):return (g*d).sum()+.5*((d@h)*d).sum()


def certificate(g,h,d,eta,config):
    k=g+d@h
    singular=torch.linalg.svdvals(k)
    scale=max(float(eta*torch.linalg.svdvals(g).sum()),1e-30)
    gap=float((k*d).sum()+eta*singular.sum())
    norm=float(torch.linalg.matrix_norm(d,ord=2)) if d.numel() else 0.
    phi=float(objective(g,h,d))
    numeric=64*torch.finfo(g.dtype).eps*scale
    return {'objective':phi,'gap':gap,'relative_gap':gap/scale,'relative_scale':scale,
            'operator_norm':norm,'feasibility_residual':max(0.,norm-eta),
            'converged':gap<=config.gap_atol+config.gap_rtol*scale and gap>=-numeric and norm<=eta+64*torch.finfo(g.dtype).eps*max(eta,1e-30),
            'zero_step':not bool(torch.count_nonzero(d)),'numeric_precision':str(g.dtype)}


@torch.no_grad()
def solve_spectral_qp(g,h,eta,previous_delta=None,config=None):
    config=config or SolverConfig();started=time.perf_counter()
    if g.dtype not in [torch.float32,torch.float64]:raise TypeError('QP requires FP32/FP64')
    if eta<0 or not torch.isfinite(g).all() or not torch.isfinite(h).all():raise ValueError('Invalid QP input')
    h,ev,correction=checked_psd(h)
    warm_used=False;warm_obj=None;rank_tol=0.;iterations=0
    if eta==0 or not torch.count_nonzero(g):d=torch.zeros_like(g)
    elif not torch.count_nonzero(h):
        polar,rank_tol=compact_polar(g);d=-eta*polar
    else:
        q,t=torch.linalg.qr(g,mode='reduced')
        x=torch.zeros_like(t);best=x.clone();best_phi=0.
        if config.warm_start and previous_delta is not None:
            warm=spectral_project(q.T@previous_delta.to(g),eta)
            warm_obj=float(objective(t,h,warm))
            if warm_obj<=0:x=warm;best=x.clone();best_phi=warm_obj;warm_used=True
        polar,rank_tol=compact_polar(t)
        candidate=-eta*polar
        if float(objective(t,h,candidate))<best_phi:best=candidate;best_phi=float(objective(t,h,best))
        # The unconstrained optimum is an exact candidate only if H is positive definite.
        if float(ev.min())>float(ev.max())*torch.finfo(h.dtype).eps*32:
            free=-torch.linalg.solve(h,t.T).T
            candidate=spectral_project(free,eta)
            phi=float(objective(t,h,candidate))
            if phi<best_phi:best=candidate;best_phi=phi
        x=best.clone();y=x.clone();accel=1.;lip=float(ev.max())
        threshold=config.gap_atol+config.gap_rtol*max(float(eta*torch.linalg.svdvals(t).sum()),1e-30)
        for iterations in range(config.max_iter+1):
            k=t+best@h
            gap=float((k*best).sum()+eta*torch.linalg.svdvals(k).sum())
            if gap<=threshold:break
            if iterations==config.max_iter:break
            nxt=spectral_project(y-(t+y@h)/lip,eta)
            phi=float(objective(t,h,nxt))
            if phi>float(objective(t,h,x)):
                y=x;accel=1.;nxt=spectral_project(y-(t+y@h)/lip,eta);phi=float(objective(t,h,nxt))
            if phi<best_phi:best=nxt.clone();best_phi=phi
            new_accel=(1+(1+4*accel*accel)**.5)/2
            y=nxt+(accel-1)/new_accel*(nxt-x);x=nxt;accel=new_accel
        d=q@best
    diagnostic=certificate(g,h,d,eta,config)
    failure=diagnostic['objective']>config.gap_atol+64*torch.finfo(g.dtype).eps*diagnostic['relative_scale']
    if failure:d=torch.zeros_like(d);diagnostic=certificate(g,h,d,eta,config)
    diagnostic.update(iterations=iterations,warm_start_used=warm_used,warm_start_objective=warm_obj,
                      numerical_failure=failure,rank_tolerance=rank_tol,psd_correction=correction,elapsed_seconds=time.perf_counter()-started)
    return d,diagnostic


@torch.no_grad()
def solve_frobenius_qp(g,h,rho):
    if rho<0:raise ValueError('Negative Frobenius radius')
    h,values,_=checked_psd(h)
    values,vectors=torch.linalg.eigh(h);values=values.clamp_min(0)
    gv=g@vectors
    if rho==0 or not torch.count_nonzero(g):return torch.zeros_like(g),{'mu':0.,'iterations':0}
    tol=torch.finfo(g.dtype).eps*max(float(values.max()),1e-30)*32
    positive=values>tol
    free=torch.zeros_like(gv);free[:,positive]=-gv[:,positive]/values[positive]
    if not torch.count_nonzero(gv[:,~positive]) and float(free.norm())<=rho:return free@vectors.T,{'mu':0.,'iterations':0}
    low=0.;high=max(float(g.norm())/rho,float(values.max()),1e-30)
    for _ in range(100):
        if float((gv/(values+high)).norm())<=rho:break
        high*=2
    for it in range(100):
        mid=(low+high)/2
        if float((gv/(values+mid)).norm())>rho:low=mid
        else:high=mid
        if high-low<max(high,1e-30)*1e-12:break
    return (-gv/(values+high))@vectors.T,{'mu':high,'iterations':it+1}

"""Research updates: current direction state never contains historical correction."""
import math
import torch
from .spectral_qp import SolverConfig,solve_spectral_qp,solve_frobenius_qp,compact_polar,certificate

METHODS=['mulora_fl_exact_polar','history_grad_muon','history_spectral','history_frobenius_qp']


def update_geometry(d):
    s=torch.linalg.svdvals(d);mass=s.sum();energy=s.square()
    if not float(mass):return {'fro':0.,'operator':0.,'stable_rank':0.,'effective_rank':0.}
    prob=s/mass
    return {'fro':float(d.norm()),'operator':float(s.max()),'stable_rank':float(energy.sum()/energy.max()),
            'effective_rank':float(torch.exp(-(prob*prob.clamp_min(1e-30).log()).sum())),
            'effective_rank_definition':'singular_value_amplitude_entropy'}


def propose(method,m,b,core,eta,lam,previous=None,solver=None,rho_factor=1.):
    solver=solver or SolverConfig()
    h=core['H'];f=core['F'];g=m+lam*(f+b@h);hh=lam*h
    if method=='history_spectral':d,diagnostic=solve_spectral_qp(g,hh,eta,previous,solver)
    elif method=='history_grad_muon':
        d=-eta*compact_polar(g)[0];diagnostic={'oracle':'exact_polar_corrected_gradient'}
    elif method=='mulora_fl_exact_polar':
        d=-eta*compact_polar(m)[0];diagnostic={'oracle':'exact_polar_current_direction'}
    elif method=='history_frobenius_qp':
        d,diagnostic=solve_frobenius_qp(g,hh,eta*rho_factor)
    else:raise ValueError(method)
    return d,diagnostic,g,hh


def paired_update_audit(m,b,core,eta,lam,a,config=None):
    result={};d0=-eta*compact_polar(m)[0]
    ds,_,_,_=propose('history_spectral',m,b,core,eta,lam,solver=config)
    g=m+lam*(core['F']+b@core['H'])
    matched=-ds.norm()*g/g.norm() if float(g.norm()) else torch.zeros_like(g)
    candidates={name:propose(name,m,b,core,eta,lam,solver=config,rho_factor=max(1,b.shape[-1]**.5))[0] for name in METHODS}
    candidates['matched_energy_gradient_direction']=matched
    candidates['matched_budget_frobenius_qp']=solve_frobenius_qp(g,lam*core['H'],float(ds.norm()))[0]
    for name,d in candidates.items():
        benefit=-float((m*d).sum());change=float(((core['F']+b@core['H'])*d).sum()+.5*((d@core['H'])*d).sum())
        factor=float((d*d0).sum()/d0.square().sum()) if float(d0.norm()) else 0.
        result[name]={**update_geometry(d),'predicted_current_gain':benefit,'historical_q_change':change,
                      'phi':-benefit+lam*change,'weight_space_fro':float((d@a).norm()),
                      'weight_space_operator':float(torch.linalg.matrix_norm(d@a,ord=2)),
                      'cosine_vs_muon':float((d*d0).sum()/(d.norm()*d0.norm()).clamp_min(1e-30)),
                      'best_uniform_scale_vs_muon':factor,'uniform_scale_residual':float((d-factor*d0).norm()/d.norm().clamp_min(1e-30))}
    return result


class HistoryOptimizer:
    def __init__(self,parameters,state,local_c,global_c,extension,client):
        self.parameters=list(parameters);self.state=state;self.local_c=local_c;self.global_c=global_c
        self.ext=extension;self.client=client;self.corrected=extension.provider=='fedmuon'
        self.diag=[];self.steps=0;self.audits=[]
    @torch.no_grad()
    def step(self,lr):
        updates=[]
        for i,b in enumerate(self.parameters):
            self.state[i].mul_(.9).add_(b.grad.float(),alpha=.1)
            m=self.state[i]-self.local_c[i]+self.global_c[i] if self.corrected else self.state[i]
            eta=lr*(max(b.shape)**.5 if self.corrected else 1.)
            core=self.ext.cores[i];lam=0. if self.ext.method=='mulora_fl_exact_polar' else self.ext.lam
            before=b.detach().clone();previous=self.ext.caches[self.client][i]
            d,diagnostic,g,hh=propose(self.ext.method,m,b,core,eta,lam,previous,self.ext.solver,self.ext.rho_factor)
            if self.ext.audit_enabled and self.client==0 and self.ext.task not in self.ext.audited_tasks and self.steps==0 and i==0:
                a=list(self.ext.model.adapters.values())[0].A
                self.audits.append(paired_update_audit(m,b,core,eta,lam,a,self.ext.solver))
                self.ext.audited_tasks.add(self.ext.task)
            b.add_(d);actual=b-before
            if self.ext.method=='history_spectral':
                actual_diag=certificate(g,hh,actual,eta,self.ext.solver)
                diagnostic.update(actual_diag)
                diagnostic['certificate_for']='actual_B_after_minus_before'
            self.ext.caches[self.client][i]=actual.clone()
            mu=-eta*compact_polar(m)[0];gradient=core['F']+before@core['H']
            gain=-float((m*mu).sum());curve=.5*float(((mu@core['H'])*mu).sum())
            q0=float(core['q0']+(core['F']*before).sum()+.5*((before@core['H'])*before).sum())
            change=float((gradient*actual).sum()+.5*((actual@core['H'])*actual).sum())
            self.diag.append({'layer':i,'step':self.steps,'eta':eta,'lambda':lam,**diagnostic,
                              'r_grad':lam*float(gradient.norm())/max(float(m.norm()),1e-30),
                              'r_curv':lam*curve/max(gain,1e-30),'history_linear_term':lam*float((gradient*mu).sum()),
                              'q_before':q0,'q_change':change,'actual_update':update_geometry(actual)})
            updates.append(actual)
        self.steps+=1
        return updates
    def flush(self,task,round_idx):
        ds=self.diag;n=len(ds)
        self.ext.event('history_solver_client',task=task,round=round_idx,client=self.client,updates=n,
            lambda_history=self.ext.lam,qp_certificate_applicable=self.ext.method=='history_spectral',mean_iterations=sum(d.get('iterations',0) for d in ds)/max(n,1),
            nonconverged=sum(not d.get('converged',True) for d in ds),zero_steps=sum(d.get('zero_step',d['actual_update']['fro']==0) for d in ds),
            max_relative_gap=max((d.get('relative_gap',0) for d in ds),default=0),
            max_feasibility_residual=max((d.get('feasibility_residual',0) for d in ds),default=0),
            max_objective=max((d.get('objective',0) for d in ds),default=0),
            solver_seconds=sum(d.get('elapsed_seconds',0) for d in ds),
            mean_r_grad=sum(d['r_grad'] for d in ds)/max(n,1),mean_r_curv=sum(d['r_curv'] for d in ds)/max(n,1),
            mean_history_q=sum(d['q_before'] for d in ds)/max(n,1),history_q_change_sum=sum(d['q_change'] for d in ds),
            first_step_per_layer=ds[:len(self.parameters)],paired_first_layer_audit=self.audits)

        self.cfg=cfg;self.method=cfg['method'];self.provider=cfg.get('direction_provider','mulora')
        if self.provider not in ['mulora','fedmuon']:raise ValueError('Unknown direction provider')
        self.solver=SolverConfig(**cfg.get('solver',{}));self.rho_factor=cfg.get('rho_factor',1.)
        self.lam=cfg.get('lambda_history',0.);self.calibrated=False;self.banks={};self.cores=[];self.caches={};self.task=-1
        self.audit_enabled=cfg.get('paired_audit',True);self.calibration={};self.basis_identity=None;self.audited_tasks=set()
    def attach(self,model,raw,manifest,train_tf,test_tf,event,root):
        self.model=model;self.raw=raw;self.manifest=manifest;self.train_tf=train_tf;self.test_tf=test_tf;self.event=event;self.root=root
        if self.cfg.get('lora_scale',1)!=1:raise ValueError('Only unit LoRA scale is supported')
        if not self.banks:
            self.banks={k:{i:InputHistory(a.A.shape[1],a.Bq.shape[0],energy_floor=self.cfg.get('energy_floor',1e-12)) for i,a in model.adapters.items()} for k in range(self.cfg['clients'])}
    def spectrum(self,x):return update_geometry(x)
    def basis_hash(self):
        value=hashlib.sha256()
        for a in self.model.adapters.values():value.update(a.A.detach().cpu().numpy().tobytes())
        return value.hexdigest()
    def checkpoint_state(self):
        return {'banks':self.banks,'cores':[{k:(v.cpu() if torch.is_tensor(v) else v) for k,v in c.items()} for c in self.cores],
                'caches':{k:[v.cpu() if v is not None else None for v in values] for k,values in self.caches.items()},
                'task':self.task,'lambda':self.lam,'calibrated':self.calibrated,'calibration':self.calibration,
                'schema_version':1,'audited_tasks':self.audited_tasks,'basis_identity':self.basis_identity,'center_ids':{k:{i:b.center for i,b in banks.items()} for k,banks in self.banks.items()},
                'position':'communication_round_boundary; epoch0/minibatch0; default sampler uses checkpointed main RNG'}
    def restore_state(self,state):
        self.audited_tasks=state['audited_tasks'];self.banks=state['banks'];self.cores=[{k:(v.cuda() if torch.is_tensor(v) else v) for k,v in c.items()} for c in state['cores']]
        self.caches={k:[v.cuda() if v is not None else None for v in values] for k,values in state['caches'].items()}
        self.basis_identity=state['basis_identity']
        if self.basis_identity is not None:assert self.basis_identity==self.basis_hash(),'Solver basis identity mismatch'
        self.task=state['task'];self.lam=state['lambda'];self.calibrated=state['calibrated'];self.calibration=state['calibration']
    def begin_task(self,t):
        started=time.perf_counter();self.task=t;self.basis_identity=self.basis_hash()
        cores,metadata=common_core(self.banks,{i:a.A for i,a in self.model.adapters.items()})
        self.cores=[{k:(v.cuda().float() if torch.is_tensor(v) else v) for k,v in c.items()} for c in cores]
        self.caches={k:[None]*len(self.cores) for k in self.banks}
        fingerprint=hashlib.sha256()
        for c in cores:
            for name in ['H','F']:fingerprint.update(c[name].numpy().tobytes())
            fingerprint.update(str(c['q0']).encode())
        self.event('historical_core',task=t,core_hash=fingerprint.hexdigest(),shared_identically_by_all_clients=True,
                   metadata=metadata,seconds=time.perf_counter()-started,
                   client_upload_bytes=sum((a.A.shape[0]**2+a.Bq.numel()+1)*8 for a in self.model.adapters.values())*2*len(self.banks),
                   server_broadcast_bytes=sum((c['H'].numel()+c['F'].numel()+1)*4 for c in cores)*len(self.banks))
        if t>0 and not self.calibrated and self.cfg.get('lambda_mode')=='training_curvature_reference' and self.method!='mulora_fl_exact_polar':self.calibrate(t)
    def calibrate(self,t):
        saved=rng_state();before=time.perf_counter();ratios=[];batches=[]
        cpt=self.manifest['cpt'];allowed=set(current_training_indices(self.manifest,t))
        try:
            # Fixed current train identities, deterministic transform; no update to B,
            # head, momentum, controls, history, cache or training sampler.
            for k in range(min(self.cfg['clients'],self.cfg.get('calibration_clients',2))):
                ids=self.manifest['partitions']['train'][t][k]
                for number,(x,y) in enumerate(loader(self.raw[0],ids,self.cfg['batch'],False)):
                    if number>=self.cfg.get('calibration_batches',2):break
                    used=ids[number*self.cfg['batch']:(number+1)*self.cfg['batch']];assert set(used)<=allowed
                    self.model.zero_grad(set_to_none=True)
                    loss=F.cross_entropy(self.model(self.test_tf(x.cuda()))[:,t*cpt:(t+1)*cpt],y.cuda()-t*cpt);loss.backward()
                    gain=curve=0.
                    for p,core in zip(self.model.b_parameters(),self.cores):
                        m=.1*p.grad.float();eta=self.cfg['lr']*(max(p.shape)**.5 if self.provider=='fedmuon' else 1.)
                        d=-eta*compact_polar(m)[0];gain-=float((m*d).sum());curve+=.5*float(((d@core['H'])*d).sum())
                    if curve>0 and gain>0:ratios.append(gain/curve)
                    batches.append({'client':k,'indices':used,'gain':gain,'curvature_cost':curve,'valid_denominator':curve>0})
            if not ratios:raise RuntimeError('Training-only lambda calibration has no nondegenerate batch')
            reference=float(torch.tensor(ratios,dtype=torch.float64).median())
            self.lam=reference*self.cfg.get('lambda_multiplier',1.);self.calibrated=True
            self.calibration={'task':t,'reference':reference,'multiplier':self.cfg.get('lambda_multiplier',1.),'lambda':self.lam,
                              'selection':'predeclared training-scale diagnostic, not validation-selected or optimal lambda','batches':batches}
            self.event('lambda_calibration',seconds=time.perf_counter()-before,**self.calibration)
        finally:self.model.zero_grad(set_to_none=True);restore_rng(saved)
    def optimizer(self,bs,momentum,old_c,server_c,client):return HistoryOptimizer(bs,momentum,old_c,server_c,self,client)
    def before_merge(self,t):
        ids=self.manifest['partitions']['train'][t][0][:self.cfg['batch']]
        assert set(ids)<=set(current_training_indices(self.manifest,t))
        self.probe_input=self.test_tf(next(iter(loader(self.raw[0],ids,self.cfg['batch'])))[0].cuda())
        with torch.no_grad():self.probe_output=self.model(self.probe_input).clone()
        center=f"{self.cfg['output']}:task{t}:merged"
        for k,banks in self.banks.items():
            for i,a in self.model.adapters.items():banks[i].recenter(t,{'q':a.Bq@a.A,'v':a.Bv@a.A},center)
    @torch.no_grad()
    def after_merge(self,t):
        started=time.perf_counter()
        torch.testing.assert_close(self.model(self.probe_input),self.probe_output,atol=5e-5,rtol=5e-5)
        del self.probe_input,self.probe_output
        for k,banks in self.banks.items():
            ids=self.manifest['partitions']['train'][t][k]
            cap=self.cfg.get('history_stats_batches')
            if cap:ids=ids[:cap*self.cfg['batch']]
            if not set(ids)<=set(current_training_indices(self.manifest,t)):raise ValueError('Non-current training data in history registration')
            for a in self.model.adapters.values():
                assert a.merged and not torch.count_nonzero(a.Bq) and not torch.count_nonzero(a.Bv)
                a.collect=True;a.tokens=0;a.stat=torch.zeros(a.A.shape[1],a.A.shape[1],device='cuda',dtype=torch.float64)
            for x,y in loader(self.raw[0],ids,self.cfg['batch']):self.model.backbone.forward_features(self.test_tf(x.cuda()))
            for i,a in self.model.adapters.items():
                a.collect=False;c=a.stat;d=a.Bq.shape[0]
                energies={p:float(((a.base.weight[s:s+d].double()@c)*a.base.weight[s:s+d].double()).sum()) for p,s in [('q',0),('v',2*d)]}
                banks[i].register(t,c,energies,a.tokens,f"{self.cfg['output']}:task{t}:merged")
                a.stat=None
            self.event('history_registration',task=t,client=k,samples=len(ids),tokens_per_block={i:b.n for i,b in banks.items()},
                       new_anchor_residual_contribution=0.,old_history_recentered_before_new_C=True)
        self.caches={k:[None]*len(self.cores) for k in self.banks}
        state_bytes=sum(b.C.numel()*8+sum(r['R'].numel()*8+16 for r in b.risks.values()) for bs in self.banks.values() for b in bs.values())
        self.event('history_boundary',task=t,seconds=time.perf_counter()-started,bank_bytes=state_bytes,adapter_merge_forward_check='passed')

def digest(path):
    h=hashlib.sha256()
    with open(path,'rb') as f:
        for x in iter(lambda:f.read(8*1024*1024),b''):h.update(x)
    return h.hexdigest()

import torch
from torch import nn
from torch.nn import functional as F


class QVAdapter(nn.Module):
    def __init__(self, linear, rank):
        super().__init__()
        self.base = linear
        d = linear.in_features
        self.register_buffer('A', torch.zeros(rank,d))
        self.Bq = nn.Parameter(torch.zeros(d,rank))
        self.Bv = nn.Parameter(torch.zeros(d,rank))
        self.merged = True
        self.collect = False
        self.stat = None
        self.tokens = 0
    def forward(self, x):
        if self.collect:
            patches = x.detach()[:,1:,:].reshape(-1,x.shape[-1]).double()
            self.stat.add_(patches.T@patches)
            self.tokens += patches.shape[0]
        y = self.base(x)
        low = F.linear(x,self.A)
        dq,dv = F.linear(low,self.Bq),F.linear(low,self.Bv)
        q,k,v = y.chunk(3,dim=-1)
        return torch.cat((q+dq,k,v+dv),dim=-1)
    @torch.no_grad()
    def start(self,a):
        if not self.merged:
            raise ValueError('Unmerged previous task')
        self.A.copy_(a)
        self.Bq.zero_(); self.Bv.zero_()
        self.merged=False
    @torch.no_grad()
    def merge(self):
        if self.merged:
            raise ValueError('Duplicate merge')
        d=self.Bq.shape[0]
        self.base.weight[:d].add_(self.Bq@self.A)
        self.base.weight[2*d:].add_(self.Bv@self.A)
        self.Bq.zero_();self.Bv.zero_()
        self.merged=True


class ContinualViT(nn.Module):
    def __init__(self, backbone, classes, rank=32, scale=16):
        super().__init__()
        self.backbone=backbone
        self.backbone.requires_grad_(False)
        self.adapters={}
        for i,b in enumerate(backbone.blocks):
            a=QVAdapter(b.attn.qkv,rank)
            b.attn.qkv=a
            # Non-owning lookup avoids duplicate state_dict aliases.
            self.adapters[str(i)]=a
        self.rows=nn.ParameterList()
        self.classes=classes
        self.scale=scale
    def add_head(self,cpt):
        for row in self.rows:
            row.requires_grad_(False)
        row=nn.Parameter(torch.empty(cpt,self.backbone.num_features,device=next(self.parameters()).device))
        nn.init.normal_(row,std=0.02)
        self.rows.append(row)
    def b_parameters(self):
        return [p for a in self.adapters.values() for p in (a.Bq,a.Bv)]
    def forward(self,x):
        features=self.backbone.forward_features(x)[:,0]
        weights=torch.cat(list(self.rows))
        return self.scale*F.linear(F.normalize(features,dim=-1),F.normalize(weights,dim=-1))


class MuLoRAFL(ContinualViT):
    method='mulora_fl'

class MuLoRAFLFedMuon(ContinualViT):
    method='mulora_fl_fedmuon'

MODELS={c.method:c for c in (MuLoRAFL,MuLoRAFLFedMuon)}

"""Shared explicit operators. No automatic parameter dispatch by shape."""
import math
import torch


def mulora_ssb(g, steps=5):
    assert g.ndim == 2
    x = g.float()
    transpose = x.shape[0] > x.shape[1]
    if transpose:
        x = x.T
    x = x / (x.norm() + 1e-7)
    for _ in range(steps):
        gram = x @ x.T
        x = 3.4445*x + (-4.7750*gram + 2.0315*(gram@gram))@x
    return x.T if transpose else x


def muon_operator(g, steps=5):
    """Takezawa operator: includes dimension scaling, unlike MuLoRA Eq.3."""
    return mulora_ssb(g, steps) * math.sqrt(max(g.shape))


def compact_polar(g):
    u, s, vh = torch.linalg.svd(g, full_matrices=False)
    tol = max(g.shape)*torch.finfo(g.dtype).eps*s.max()
    keep = s > tol
    return u[:, keep] @ vh[keep]


def rrs(s, history, rank, epsilon_relative=1e-6):
    s, history = s.double(), history.double()
    # Training-only scale; explicit, deterministic first-task regularization.
    scale = max(float(history.diag().mean()), float(s.diag().mean()), 1e-12)
    epsilon = epsilon_relative * scale
    eye = torch.eye(s.shape[0], dtype=s.dtype, device=s.device)
    for attempt in range(8):
        jitter = epsilon * 10**attempt
        l, info = torch.linalg.cholesky_ex((history+history.T)/2 + jitter*eye)
        if int(info) == 0:
            break
    else:
        raise RuntimeError('Historical metric failed Cholesky')
    tmp = torch.linalg.solve_triangular(l, s, upper=False)
    white = torch.linalg.solve_triangular(l, tmp.T, upper=False).T
    values, vectors = torch.linalg.eigh((white+white.T)/2)
    z = torch.linalg.solve_triangular(l.T, vectors[:, -rank:], upper=True)
    q, _ = torch.linalg.qr(z, mode='reduced')
    return q.T.float(), {'epsilon': epsilon, 'jitter': jitter, 'eigenvalues': values[-rank:].tolist()}


def aggregate(bs, bases, weights):
    if not all(torch.equal(bases[0], a) for a in bases[1:]):
        raise ValueError('Client A mismatch')
    if abs(sum(weights)-1) > 1e-6:
        raise ValueError('Weights must sum to one')
    return sum(p*b for p,b in zip(weights,bs))


class History:
    def __init__(self):
        self.raw = {}
        self.committed = set()
    def commit(self, task, stats):
        if task in self.committed:
            raise ValueError('Historical statistics already committed')
        for name, s in stats.items():
            self.raw[name] = self.raw.get(name, torch.zeros_like(s)) + s
        self.committed.add(task)


class ClientMuon:
    def __init__(self, parameters, state, local_c, global_c, corrected):
        self.parameters = list(parameters)
        self.state = state
        self.local_c = local_c
        self.global_c = global_c
        self.corrected = corrected
    @torch.no_grad()
    def step(self, lr):
        updates = []
        for i,p in enumerate(self.parameters):
            if p.grad is None:
                raise RuntimeError('Missing B gradient')
            self.state[i].mul_(0.9).add_(p.grad.float(), alpha=0.1)
            h = self.state[i]
            if self.corrected:
                h = h - self.local_c[i] + self.global_c[i]
            operator = muon_operator if self.corrected else mulora_ssb
            update = -lr*operator(h)
            p.add_(update)
            updates.append(update)
        return updates


def spectrum(x):
    s = torch.linalg.svdvals(x.float())
    energy = s.square()
    p = energy / energy.sum().clamp_min(1e-30)
    return {'fro': float(x.norm()), 'stable_rank': float(energy.sum()/energy.max().clamp_min(1e-30)),
            'effective_rank': float(torch.exp(-(p*p.clamp_min(1e-30).log()).sum())) if float(energy.sum()) else 0.0}

def upstream_split(train_labels,test_labels,cpt,clients,alpha,seed):
    # Reuse the actual upstream function without importing its unrelated NLP deps.
    source=(UPSTREAM/'_datasets/_utils.py').read_text()
    tree=ast.parse(source)
    cls=next(n for n in tree.body if isinstance(n,ast.ClassDef) and n.name=='BaseDataset')
    fn=next(n for n in cls.body if isinstance(n,ast.FunctionDef) and n.name=='_split_fcil')
    module=ast.Module(body=[fn],type_ignores=[])
    ns={'np':np,'torch':torch}
    exec(compile(ast.fix_missing_locations(module),str(UPSTREAM/'_datasets/_utils.py'),'exec'),ns)
    obj=SimpleNamespace(N_CLASSES_PER_TASK=cpt,N_TASKS=10,train_data=[],train_targets=[],test_data=[],test_targets=[])
    for split,labels in [('train',train_labels),('test',test_labels)]:
        setattr(obj,split+'_dataset',SimpleNamespace(data=np.arange(len(labels)),targets=np.array(labels)))
    np_state,torch_state=np.random.get_state(),torch.get_rng_state()
    try:

        ns['_split_fcil'](obj,clients,'distribution',alpha)
    finally:
        np.random.set_state(np_state);torch.set_rng_state(torch_state)
    return {split:[[x.tolist() for x in task] for task in getattr(obj,split+'_data')] for split in ['train','test']}

def test_statistics_rrs_and_commit():
    torch.manual_seed(13)

    torch.testing.assert_close(s,x.T@x)

    hist=History();hist.commit(0,{'x':s})

    torch.testing.assert_close(hist.raw['x'],s)

def ns_reference(g):
    # Deliberately larger Gram, independent polynomial expression.
    x=g.float()/(g.float().norm()+1e-7)
    for _ in range(5):x=3.4445*x-4.7750*x@(x.T@x)+2.0315*x@(x.T@x)@(x.T@x)
    return x*max(g.shape)**.5


def test_two_clients_two_matrices_two_rounds_reference():
    torch.manual_seed(8)
    shapes=[(5,2),(3,4)];weights=[.5,.5]
    server=[torch.zeros(s) for s in shapes];c=[torch.zeros(s) for s in shapes]
    ms=[[torch.zeros(s) for s in shapes] for _ in range(2)]
    cs=copy.deepcopy(ms);rm=copy.deepcopy(ms);rc=copy.deepcopy(cs);rs=copy.deepcopy(server);rg=copy.deepcopy(c)
    for r in range(2):
        ends=[];refs=[]
        for k in range(2):
            params=[torch.nn.Parameter(v.clone()) for v in server];ref=[v.clone() for v in rs]
            opt=ClientMuon(params,ms[k],cs[k],c,True)
            frozen=copy.deepcopy(cs[k])
            for step in range(3):
                for j,p in enumerate(params):
                    grad=torch.randn_like(p);p.grad=grad.clone()
                    rm[k][j]=.9*rm[k][j]+.1*grad
                    ref[j]-=.002*ns_reference(rm[k][j]-rc[k][j]+rg[j])
                opt.step(.002)
                for j,p in enumerate(params):
                    torch.testing.assert_close(p,ref[j],atol=1e-6,rtol=1e-5)
                    torch.testing.assert_close(cs[k][j],frozen[j])
                    torch.testing.assert_close(ms[k][j],rm[k][j])
            ends.append([p.detach().clone() for p in params]);refs.append(ref)
        cs=copy.deepcopy(ms);rc=copy.deepcopy(rm)
        c=[sum(weights[k]*cs[k][j] for k in range(2)) for j in range(2)]
        rg=[sum(weights[k]*rc[k][j] for k in range(2)) for j in range(2)]
        server=[sum(weights[k]*ends[k][j] for k in range(2)) for j in range(2)]
        rs=[sum(weights[k]*refs[k][j] for k in range(2)) for j in range(2)]

def test_single_client_centralized_degeneracy():
    # Central reference independently follows Eq.3, preserves momentum across rounds.
    from fcl.math import mulora_ssb
    torch.manual_seed(33)
    fed=QVAdapter(torch.nn.Linear(7,21),3)
    central=copy.deepcopy(fed)
    fh,ch=History(),History()
    for task in range(2):
        x=torch.randn(17,7,dtype=torch.float64);s=x.T@x
        a,_=rrs(s,fh.raw.get('x',torch.zeros_like(s)),3)
        ac,_=rrs(s,ch.raw.get('x',torch.zeros_like(s)),3)
        fed.start(a);central.start(ac)
        fm=[torch.zeros_like(fed.Bq),torch.zeros_like(fed.Bv)]
        cm=copy.deepcopy(fm);zeros=copy.deepcopy(fm)
        params=[fed.Bq,fed.Bv];refs=[central.Bq,central.Bv]
        opt=ClientMuon(params,fm,zeros,zeros,False)
        for rnd in range(3):
            for step in range(2):
                lr=.002*(1+np.cos(np.pi*(rnd*2+step)/5))/2
                batch=torch.randn(2,4,7);target=torch.randn(2,4,21)
                for model in [fed,central]:
                    model.zero_grad();((model(batch)-target)**2).mean().backward()
                opt.step(lr)
                with torch.no_grad():
                    for j,p in enumerate(refs):
                        cm[j]=.9*cm[j]+.1*p.grad
                        # Independent no-dimension-multiplier reference.
                        p.add_(ns_reference(cm[j])/max(p.shape)**.5,alpha=-lr)
                for p,q in zip(params,refs):torch.testing.assert_close(p,q,atol=1e-6,rtol=1e-5)
            # FedAvg with one participant is identity, no reset at round boundary.
            for p in params:
                with torch.no_grad():p.copy_(aggregate([p.detach().clone()],[a],[1.]))
        fed.merge();central.merge();fh.commit(task,{'x':s});ch.commit(task,{'x':s})
        torch.testing.assert_close(fed.base.weight,central.base.weight,atol=1e-6,rtol=1e-5)
        assert fh.committed==ch.committed==set(range(task+1))

from pathlib import Path
root=Path(os.environ['PROJECT_ROOT']);os.chdir(root)
watch=root.parent
statepath=root/'reports/research-state.json'
if (root/'reports/USER_PAUSE.json').exists():raise SystemExit('User paused research experiments for Pro implementation review')
states=json.loads(statepath.read_text()) if statepath.exists() else {}
phase=os.environ.get('RESEARCH_PHASE','smoke')
queue=json.loads((root/'research/history_spectral'/f'{phase}_queue.json').read_text())

def record():
    tmp=statepath.with_suffix('.tmp');tmp.write_text(json.dumps(states,indent=2));tmp.replace(statepath)

def qualify(cfg,out):
    events=[json.loads(x) for x in (out/'events.jsonl').read_text().splitlines()]
    records={(e['task'],e['round'],e['client']):e for e in events if e['kind']=='client'}
    first_task=1 if cfg['method']!='mulora_fl_exact_polar' else 0
    expected=(cfg['tasks']-first_task)*cfg['rounds']*cfg['clients']
    assert len(records)==expected,(len(records),expected)
    if not cfg.get('train_batches'):
        assert all(e['steps']==cfg['epochs']*((e['N']+cfg['batch']-1)//cfg['batch']) and e['visited']==cfg['epochs']*e['N'] for e in records.values())
    diagnostics=[e for e in events if e['kind']=='history_solver_client']
    updates=sum(e['updates'] for e in diagnostics);nonconverged=sum(e['nonconverged'] for e in diagnostics)
    ratio=nonconverged/max(updates,1)
    result={'qualified':cfg['method']!='history_spectral' or ratio<=.01,'updates':updates,'nonconverged':nonconverged,
            'nonconverged_fraction':ratio,'zero_steps':sum(e['zero_steps'] for e in diagnostics),
            'max_relative_gap':max((e['max_relative_gap'] for e in diagnostics),default=0),'rule':'spectral QP <=1% actual-step nonconvergence; numerical qualification only'}
    (out/'QUALIFICATION.json').write_text(json.dumps(result,indent=2))
    return result['qualified']

for item in queue:
    if (root/'reports/USER_PAUSE.json').exists():raise SystemExit('User pause: research queue disabled')
    name=item['config'];cfg=json.loads((root/name).read_text());out=root/cfg['output'];s=states.setdefault(name,{'status':'not_started','phase':phase})
    if (out/'COMPLETE.json').exists():
        s['status']='completed' if qualify(cfg,out) else 'qualification_failed';record()
        if s['status']!='completed':break
        continue
    if s['status'] in ['failed','qualification_failed','budget_exhausted','blocked']:break
    if s.get('pid'):
        try:os.kill(s['pid'],0)
        except ProcessLookupError:pass
        else:raise SystemExit('Prior research child still exists; refusing duplicate')
    free=int(subprocess.check_output(['nvidia-smi','--query-gpu=memory.free','--format=csv,noheader,nounits','-i',os.environ['CUDA_VISIBLE_DEVICES']],text=True).strip())
    if free<16000:s.update(status='blocked',reason='Insufficient free GPU memory');record();break
    env=dict(os.environ,ENTRY_MODULE='fcl.history_train',RUN_CONFIG=str(root/name));env.pop('ENTRY_FILE',None);env.pop('RESUME',None);env.pop('FORK_TASK1',None)
    if (out/'latest.pt').exists():env['RESUME']=str(out/'latest.pt')
    elif item.get('fork_task1'):
        fork=root/item['fork_task1']
        if not fork.exists():s.update(status='blocked',reason='Shared task1 checkpoint unavailable');record();break
        env['FORK_TASK1']=str(fork)
    started=s.setdefault('started',time.time());s.update(status='running',deadline=started+86400,gpu=os.environ['CUDA_VISIBLE_DEVICES'])
    out.mkdir(parents=True,exist_ok=True)
    with (out/'console.log').open('a') as log:
        child=subprocess.Popen([sys.executable,'/data/bmw/workers/e17.py'],env=env,stdout=log,stderr=subprocess.STDOUT,start_new_session=True)
        s['pid']=child.pid;record()
        while child.poll() is None:
            # Whole-project budget is deliberately stricter than per-run storage.
            allocated=sum(p.stat().st_blocks*512 for p in watch.rglob('*') if p.is_file() and not p.is_symlink())
            if time.time()>started+85500 or allocated>37_000_000_000:
                os.killpg(child.pid,signal.SIGTERM)
                try:child.wait(timeout=60)
                except subprocess.TimeoutExpired:os.killpg(child.pid,signal.SIGKILL);child.wait()
                s.update(status='budget_exhausted',allocated_bytes=allocated);break
            time.sleep(15)
    s['exit_code']=child.returncode;s['ended']=time.time()
    if (out/'COMPLETE.json').exists():s['status']='completed' if qualify(cfg,out) else 'qualification_failed'
    elif s['status']!='budget_exhausted':s['status']='failed'
    record()
    if s['status']!='completed':break
